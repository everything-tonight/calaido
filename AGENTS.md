# AGENTS.md

## Quick Start

```bash
pnpm install        # Node 24.16.0, pnpm 11.0.0 (strict: only pnpm allowed)
pnpm dev            # Vite dev server on localhost:5173
pnpm build          # typecheck + vite build
pnpm lint:eslint    # Run eslint
pnpm type:check     # vue-tsc -b
```

## Architecture

Vue 3 + TypeScript + Vite SPA. Feature-based modular structure:

```
src/
├── app/              # App shell: main.ts, plugins (router, pinia, unhead), assets
└── modules/
    ├── core/         # Shared infrastructure
    │   ├── app/      # Core routes (catch-all 404, must be last in router)
    │   ├── layouts/  # Layout components (dashboard-layout, default-layout)
    │   ├── pages/    # Core pages (not-found)
    │   └── shared/   # Shared libs: ofetch HTTP client, swagger codegen, utils
    └── booking/      # Feature module
        ├── app/      # Feature routes
        ├── entities/ # Domain entities (order, reservation, restaurant, table)
        │   └── model/  # Types + valibot validators per entity
        ├── pages/    # Feature pages (booking)
        │   ├── api/  # API service functions
        │   ├── model/# Page-specific types/validators
        │   └── ui/   # Vue components
        └── widgets/  # Reusable UI components (booking-calendar, booking-filters)
```

## Key Conventions

- **Path aliases**: `:app/*` → `src/app/*`, `:modules/*` → `src/modules/*`
- **API client**: `src/modules/core/shared/lib/ofetch/index.ts` — configured with `CLIENT_URL_GATEWAY` env var
- **Validation**: Valibot schemas. Entity validators extend generated swagger types with transforms
- **Generated code**: `src/modules/core/shared/lib/swagger/valibot.gen.ts` — auto-generated by `@hey-api/openapi-ts`, DO NOT EDIT manually
- **Swagger input**: `SERVER_URL_GATEWAY_SWAGGER` env var points to OpenAPI spec
- **State**: Pinia stores + `@pinia/colada` for query caching
- **Styling**: Tailwind CSS 4 via `cn()` utility (clsx + tailwind-merge)
- **Router order**: Core routes must be registered AFTER feature routes (catch-all pattern)

## Environment

- `.env.local` — local overrides (gitignored)
- `.env.example` — template with required vars
- `CLIENT_*` vars exposed to browser code, `SERVER_*` vars only for build/dev server
- Required: `CLIENT_URL_GATEWAY` (API base URL), `SERVER_URL_GATEWAY_SWAGGER` (OpenAPI spec URL)

## Linting & Formatting

- ESLint with `@antfu/eslint-config` — no Prettier, ESLint handles formatting
- Pre-commit hook: `lint-staged` runs `eslint --fix` on staged files
- Commit messages: conventional commits enforced via `commitlint`
- VS Code: use workspace TypeScript, ESLint auto-fix on save

## Gotchas

- No test framework configured — verify changes manually or add tests if needed
- `pnpm build` fails if typecheck fails (runs `vue-tsc -b` first)
- Generated swagger file changes when API spec updates — regenerate with vite plugin or `pnpm openapi-ts`
- Entity validators spread generated swagger schemas (`...vMainOrder.entries`) and override/extend fields
- Russian language in UI strings and some code comments
